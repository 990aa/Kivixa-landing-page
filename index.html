Model Context Protocol (MCP)

  • AI-powered tool execution — let AI perform actions on your behalf
  • File operations: read, write, delete; create folders
  • Directory listing and markdown export
  • Lua scripting integration for calendar and timer scripts
  • Safety first — every execution needs your confirmation
  • Sandboxed: file access restricted to your notes folder

Smart Model Manager

  • Automatic download with resume support
  • Background downloading while the app is minimized
  • Progress tracking with speed and ETA display
  • GPU acceleration via Vulkan and Metal

  • Audio intelligence

    Whisper-based offline speech-to-text, Kokoro neural TTS, voice activity detection, a neural dictation bar, voice notes with karaoke transcript highlighting, voice search, and an AI walkie-talkie — fully offline.

Beyond the basics

A workspace that keeps up with you.

Version-controlled notes, a scriptable plugin layer, timers, math, canvases and a built-in browser — no extensions to hunt for.

Notes & documents

A rich markdown editor powered by AppFlowy Editor — bold, lists, checkboxes, quotes, code blocks, hyperlinks and real-time autosave. Floating text boxes anywhere on the canvas, folder organization, .kvx / .md / .txt and PDF support, bidirectional note linking, plus image and video embedding with resize, rotate and comment annotations.

Life Git version control

Time travel — roll back any note to any previous version with a slider. Auto-snapshots when you stop typing, content-addressable SHA-256 storage, commit history with timestamps, per-file history and version comparison before restoring. Zero configuration.

Scriptable plugins

Lua 5.3 scripting with a full App API — App:createNote, App:readNote, App:findNotes and more. Example plugins included, a plugin manager and an ad-hoc script runner.

Productivity clock

Pomodoro, 52/17 and Ultradian templates, session tags, quick-switch presets, multi-timer orchestration, chained routines with auto-advance, statistics, smart notifications and a floating clock widget.

Math module

A full mathematics suite on a Rust backend — scientific calculator, algebra, calculus with partial derivatives and multiple integrals, statistics and hypothesis testing, discrete math, plus 2D, parametric and polar graphing.

Digital canvas

Pressure-sensitive pen, highlighter, laser pointer, multi-mode eraser and shape tools on an infinite canvas with layers, backgrounds, grid snapping and transform tools.

In-app browser

A built-in browser with find-in-page, a developer console, dark-mode injection, permission dialogs, quick links, download handoff and a floating resizable window.

Quick notes

Ephemeral notes for thoughts that don't need permanent storage — text or handwriting mode, auto-expiration from 15 minutes to one week, an expiry countdown and one-tap access from the floating hub.
